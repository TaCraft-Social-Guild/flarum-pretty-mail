# FlarumPrettyMail

![License](https://img.shields.io/badge/license-MIT-blue.svg) [![Latest Stable Version](https://img.shields.io/packagist/v/tacraft-sociality/flarum-pretty-mail.svg)](https://packagist.org/packages/tacraft-sociality/flarum-pretty-mail) [![Total Downloads](https://img.shields.io/packagist/dt/tacraft-sociality/flarum-pretty-mail.svg)](https://packagist.org/packages/tacraft-sociality/flarum-pretty-mail)

A [Flarum](https://flarum.org) extension. A Flarum extension. Make custom HTML templates for emails.

## Installation

Install with composer:

```sh
composer require tacraft-sociality/flarum-pretty-mail:"*"
```

## Updating

```sh
composer update tacraft-sociality/flarum-pretty-mail:"*"
php flarum migrate
php flarum cache:clear
```
